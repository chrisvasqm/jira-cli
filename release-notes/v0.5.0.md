## English

You can now move a ticket to another column or status from the terminal.

### What's new

- **Move a ticket.** Run `jira ticket move ABC-123 "In Progress"`. You can use the name of a status, a column on your board, or a workflow step.
- **See where a ticket can go.** Run `jira ticket move ABC-123` with no target. It lists the statuses the ticket can move to right now.
- **Clear errors.** If Jira does not allow a move, the CLI tells you and lists the moves that are allowed.
- **Use it with AI assistants.** Add `--json` to get a result that tools and AI assistants can read.

### How to install or update

You need [Node.js](https://nodejs.org) 24 or newer. Then run:

```sh
npm install -g https://github.com/chrisvasqm/jira-cli/releases/download/v0.5.0/jira-cli-0.5.0.tgz
```

## Español

Ahora puedes mover un ticket a otra columna o estado desde la terminal.

### Novedades

- **Mueve un ticket.** Ejecuta `jira ticket move ABC-123 "In Progress"`. Puedes usar el nombre de un estado, de una columna de tu tablero o de un paso del flujo de trabajo.
- **Mira a dónde puede ir un ticket.** Ejecuta `jira ticket move ABC-123` sin destino. Muestra los estados a los que el ticket puede pasar ahora.
- **Errores claros.** Si Jira no permite un cambio, la CLI te lo dice y muestra los cambios permitidos.
- **Úsalo con asistentes de IA.** Agrega `--json` para obtener un resultado que otras herramientas y asistentes de IA pueden leer.

### Cómo instalar o actualizar

Necesitas [Node.js](https://nodejs.org) 24 o una versión más nueva. Después ejecuta:

```sh
npm install -g https://github.com/chrisvasqm/jira-cli/releases/download/v0.5.0/jira-cli-0.5.0.tgz
```
