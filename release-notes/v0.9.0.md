## English

Boards now work like tickets and comments: one word for the thing, one for the action.

### What's new

- **See all your boards.** Run `jira board list`. A `*` marks the board from your setup.
- **Look at any board.** Run `jira board view 2` to see board 2. `jira board` alone still shows your own board, with the same filters as before.
- **Switch your default board.** Run `jira board use 2`. From then on, `jira board` shows board 2 and new tickets go to its project. You do not need to run the setup again.

### What changed

- The `--board` option from version 0.7.0 is gone. Use `jira board view <id>` instead.

### How to install or update

You need [Node.js](https://nodejs.org) 24 or newer. Then run:

```sh
npm install -g https://github.com/chrisvasqm/jira-cli/releases/download/v0.9.0/jira-cli-0.9.0.tgz
```

## Español

Los tableros ahora funcionan como los tickets y los comentarios: una palabra para la cosa y otra para la acción.

### Novedades

- **Mira todos tus tableros.** Ejecuta `jira board list`. Un `*` marca el tablero de tu configuración.
- **Mira cualquier tablero.** Ejecuta `jira board view 2` para ver el tablero 2. `jira board` solo sigue mostrando tu tablero, con los mismos filtros de antes.
- **Cambia tu tablero predeterminado.** Ejecuta `jira board use 2`. Desde ese momento, `jira board` muestra el tablero 2 y los tickets nuevos van a su proyecto. No necesitas volver a hacer la configuración.

### Qué cambió

- La opción `--board` de la versión 0.7.0 ya no existe. Usa `jira board view <id>` en su lugar.

### Cómo instalar o actualizar

Necesitas [Node.js](https://nodejs.org) 24 o una versión más nueva. Después ejecuta:

```sh
npm install -g https://github.com/chrisvasqm/jira-cli/releases/download/v0.9.0/jira-cli-0.9.0.tgz
```
