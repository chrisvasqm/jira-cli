## English

The first version of jira-cli. You can now see your Jira board from the terminal.

### What's new

- **Connect to your Jira.** Run `jira setup`. It asks for your Jira address, your email, and an API token. Then you pick your board. The tool saves this in the folder where you run it, so each project can use a different Jira or board.
- **See your board.** Run `jira board`. It shows your tickets, grouped by column, the same way you see them in Jira.
- **Filter the board.** Show only your tickets with `--assignee me`. Show one column with `--status "In Progress"`.
- **Use it with AI assistants.** Add `--json` to any command to get output that tools and AI assistants can read.
- **Get help.** Run `jira -h` to see all commands.

### How to install

You need [Node.js](https://nodejs.org) 24 or newer. Then run:

```sh
npm install -g https://github.com/chrisvasqm/jira-cli/releases/download/v0.1.0/jira-cli-0.1.0.tgz
```

Get your API token at https://id.atlassian.com/manage/api-tokens.

Keep your token safe. `jira setup` saves it in a file named `.jira-cli.json`. If the folder is a git project, add `.jira-cli.json` to your `.gitignore` file so the token is never uploaded. Do not share this file.

## Español

La primera versión de jira-cli. Ahora puedes ver tu tablero de Jira desde la terminal.

### Novedades

- **Conéctate a tu Jira.** Ejecuta `jira setup`. Te pide la dirección de tu Jira, tu correo y un token de API. Después eliges tu tablero. La herramienta guarda esto en la carpeta donde la ejecutas, así cada proyecto puede usar un Jira o un tablero diferente.
- **Mira tu tablero.** Ejecuta `jira board`. Muestra tus tickets agrupados por columna, igual que en Jira.
- **Filtra el tablero.** Muestra solo tus tickets con `--assignee me`. Muestra una sola columna con `--status "In Progress"`.
- **Úsalo con asistentes de IA.** Agrega `--json` a cualquier comando para obtener un resultado que otras herramientas y asistentes de IA pueden leer.
- **Pide ayuda.** Ejecuta `jira -h` para ver todos los comandos.

### Cómo instalar

Necesitas [Node.js](https://nodejs.org) 24 o una versión más nueva. Después ejecuta:

```sh
npm install -g https://github.com/chrisvasqm/jira-cli/releases/download/v0.1.0/jira-cli-0.1.0.tgz
```

Obtén tu token de API en https://id.atlassian.com/manage/api-tokens.

Protege tu token. `jira setup` lo guarda en un archivo llamado `.jira-cli.json`. Si la carpeta es un proyecto de git, agrega `.jira-cli.json` a tu archivo `.gitignore` para que el token nunca se suba. No compartas este archivo.
