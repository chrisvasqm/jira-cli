## English

You can now fix or remove comments, and look at any board.

### What's new

- **Edit a comment.** Run `jira comment edit ABC-123 10001 "New text"`. The comment number is shown next to each comment, for example `#10001`.
- **Delete a comment.** Run `jira comment delete ABC-123 10001`. The CLI asks you to type "yes" first. Add `--yes` to skip the question in scripts and AI assistants.
- **Look at another board.** Run `jira board --board 2` to see a board other than the one from your setup.
- **Clearer move errors.** When a ticket cannot move to a status, the message now lists the statuses it can move to.

### How to install or update

You need [Node.js](https://nodejs.org) 24 or newer. Then run:

```sh
npm install -g https://github.com/chrisvasqm/jira-cli/releases/download/v0.7.0/jira-cli-0.7.0.tgz
```

## Español

Ahora puedes corregir o borrar comentarios, y ver cualquier tablero.

### Novedades

- **Edita un comentario.** Ejecuta `jira comment edit ABC-123 10001 "Texto nuevo"`. El número del comentario aparece junto a cada comentario, por ejemplo `#10001`.
- **Borra un comentario.** Ejecuta `jira comment delete ABC-123 10001`. La CLI te pide escribir "yes" primero. Agrega `--yes` para saltar la pregunta en scripts y asistentes de IA.
- **Mira otro tablero.** Ejecuta `jira board --board 2` para ver un tablero distinto al de tu configuración.
- **Errores más claros al mover.** Cuando un ticket no puede pasar a un estado, el mensaje ahora muestra los estados a los que sí puede pasar.

### Cómo instalar o actualizar

Necesitas [Node.js](https://nodejs.org) 24 o una versión más nueva. Después ejecuta:

```sh
npm install -g https://github.com/chrisvasqm/jira-cli/releases/download/v0.7.0/jira-cli-0.7.0.tgz
```
