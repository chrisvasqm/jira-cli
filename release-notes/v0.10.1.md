## English

This update changes how the CLI is packaged. The commands stay the same.

### What's better

- **Safer install.** The CLI now comes as one file that already holds everything it needs. Installing it no longer downloads other packages, so what you install is exactly what was tested.
- **Faster install.** With nothing else to download, the install takes about a second.

### How to install or update

You need [Node.js](https://nodejs.org) 24 or newer. Then run:

```sh
npm install -g https://github.com/chrisvasqm/jira-cli/releases/download/v0.10.1/jira-cli-0.10.1.tgz
```
