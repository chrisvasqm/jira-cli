## English

This update makes the CLI safer, clearer and faster. Nothing you use today changes how it works.

### What's better

- **Safer with your token.** The setup only accepts `https://` addresses, the token can no longer come back with the Up arrow key, and your config file is locked down before the token is written.
- **Ctrl+C always works.** You can now stop the CLI while it waits for Jira.
- **No more endless waits.** If Jira does not answer in 30 seconds, the CLI stops and tells you. When Jira says "slow down", the CLI waits as long as Jira asks and tries again, also when it creates or changes things.
- **Clearer messages.** Running `jira ticket` alone now shows its commands. A wrong board number says the board does not exist. Network problems say why (for example, a typo in the address). Long error pages are shortened.
- **Better matching.** `--assignee ana@example.com` finds the right person even when other names start the same way. `jira board --assignee none` shows tickets that nobody works on.
- **Faster boards.** Big boards load in fewer steps.

### For scripts and AI assistants

- A wrong command or a missing argument now ends with exit code 2, so scripts can tell it apart from a Jira error (exit code 1).

### How to install or update

You need [Node.js](https://nodejs.org) 24 or newer. Then run:

```sh
npm install -g https://github.com/chrisvasqm/jira-cli/releases/download/v0.10.0/jira-cli-0.10.0.tgz
```

## Español

Esta actualización hace la CLI más segura, más clara y más rápida. Nada de lo que ya usas cambia su forma de funcionar.

### Qué mejoró

- **Más segura con tu token.** La configuración solo acepta direcciones `https://`, el token ya no puede volver a aparecer con la flecha hacia arriba, y tu archivo de configuración se protege antes de guardar el token.
- **Ctrl+C siempre funciona.** Ahora puedes detener la CLI mientras espera a Jira.
- **No más esperas sin fin.** Si Jira no responde en 30 segundos, la CLI se detiene y te avisa. Cuando Jira pide ir más despacio, la CLI espera lo que Jira pide y lo intenta otra vez, también al crear o cambiar cosas.
- **Mensajes más claros.** Ejecutar `jira ticket` solo ahora muestra sus comandos. Un número de tablero equivocado dice que el tablero no existe. Los problemas de red dicen por qué (por ejemplo, un error en la dirección). Las páginas de error largas se acortan.
- **Mejor búsqueda de personas.** `--assignee ana@example.com` encuentra a la persona correcta aunque otros nombres empiecen igual. `jira board --assignee none` muestra los tickets que nadie tiene asignados.
- **Tableros más rápidos.** Los tableros grandes cargan en menos pasos.

### Para scripts y asistentes de IA

- Un comando equivocado o un dato que falta ahora termina con el código de salida 2, así los scripts pueden distinguirlo de un error de Jira (código 1).

### Cómo instalar o actualizar

Necesitas [Node.js](https://nodejs.org) 24 o una versión más nueva. Después ejecuta:

```sh
npm install -g https://github.com/chrisvasqm/jira-cli/releases/download/v0.10.0/jira-cli-0.10.0.tgz
```
