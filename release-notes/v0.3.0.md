## English

You can now read the whole conversation on a ticket and reply to it from the terminal.

### What's new

- **Read all comments.** Run `jira comment list ABC-123` to see the comments on a ticket, oldest first. It shows up to 50 comments. Use `--limit 200` to see more.
- **Add a comment.** Run `jira comment add ABC-123 "Fixed in the latest build"`. Leave an empty line between paragraphs. Put code between ``` lines to show it as code.
- **Write longer comments in a file.** Run `jira comment add ABC-123 --file notes.md`, or use `--file -` to send the text from another command.
- **Use it with AI assistants.** Add `--json` to any of these commands to get a result that tools and AI assistants can read.

### How to install or update

You need [Node.js](https://nodejs.org) 24 or newer. Then run:

```sh
npm install -g https://github.com/chrisvasqm/jira-cli/releases/download/v0.3.0/jira-cli-0.3.0.tgz
```

## Español

Ahora puedes leer toda la conversación de un ticket y responder desde la terminal.

### Novedades

- **Lee todos los comentarios.** Ejecuta `jira comment list ABC-123` para ver los comentarios de un ticket, del más antiguo al más nuevo. Muestra hasta 50 comentarios. Usa `--limit 200` para ver más.
- **Agrega un comentario.** Ejecuta `jira comment add ABC-123 "Corregido en la última versión"`. Deja una línea vacía entre párrafos. Pon el código entre líneas ``` para mostrarlo como código.
- **Escribe comentarios largos en un archivo.** Ejecuta `jira comment add ABC-123 --file notas.md`, o usa `--file -` para enviar el texto desde otro comando.
- **Úsalo con asistentes de IA.** Agrega `--json` a cualquiera de estos comandos para obtener un resultado que otras herramientas y asistentes de IA pueden leer.

### Cómo instalar o actualizar

Necesitas [Node.js](https://nodejs.org) 24 o una versión más nueva. Después ejecuta:

```sh
npm install -g https://github.com/chrisvasqm/jira-cli/releases/download/v0.3.0/jira-cli-0.3.0.tgz
```
