## English

You can now change a ticket without opening Jira.

### What's new

- **Edit a ticket.** Run `jira ticket edit ABC-123` with what you want to change. Only the things you name change.
  - `--summary "New title"` changes the title.
  - `--description "..."` or `--description-file notes.md` changes the description.
  - `--priority High` changes the priority.
  - `--assignee me`, `--assignee ana@example.com` or `--assignee none` changes who works on it.
  - `--add-label urgent` and `--remove-label later` change the labels. Repeat them for more labels.
- **Use it with AI assistants.** Add `--json` to get a result that tools and AI assistants can read.

### How to install or update

You need [Node.js](https://nodejs.org) 24 or newer. Then run:

```sh
npm install -g https://github.com/chrisvasqm/jira-cli/releases/download/v0.4.0/jira-cli-0.4.0.tgz
```

Ahora puedes cambiar un ticket sin abrir Jira.

- **Edita un ticket.** Ejecuta `jira ticket edit ABC-123` con lo que quieres cambiar. Solo cambia lo que indicas.
  - `--summary "Nuevo título"` cambia el título.
  - `--description "..."` o `--description-file notas.md` cambia la descripción.
  - `--priority High` cambia la prioridad.
  - `--assignee me`, `--assignee ana@example.com` o `--assignee none` cambia quién trabaja en él.
  - `--add-label urgente` y `--remove-label luego` cambian las etiquetas. Repítelos para más etiquetas.
- **Úsalo con asistentes de IA.** Agrega `--json` para obtener un resultado que otras herramientas y asistentes de IA pueden leer.

### Cómo instalar o actualizar

Necesitas [Node.js](https://nodejs.org) 24 o una versión más nueva. Después ejecuta:

```sh
npm install -g https://github.com/chrisvasqm/jira-cli/releases/download/v0.4.0/jira-cli-0.4.0.tgz
```
