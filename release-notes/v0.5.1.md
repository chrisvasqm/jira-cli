## English

This update fixes the setup.

### What's fixed

- **Setup no longer stops after the API token.** Before, `jira setup` stopped with "Input ended before all prompts were answered" right after you typed your token. Now it goes on to the board question as it should.

### How to install or update

You need [Node.js](https://nodejs.org) 24 or newer. Then run:

```sh
npm install -g https://github.com/chrisvasqm/jira-cli/releases/download/v0.5.1/jira-cli-0.5.1.tgz
```

## Español

Esta actualización corrige la configuración.

### Qué se corrigió

- **La configuración ya no se detiene después del token de API.** Antes, `jira setup` se detenía con "Input ended before all prompts were answered" justo después de escribir tu token. Ahora sigue con la pregunta del tablero como debe.

### Cómo instalar o actualizar

Necesitas [Node.js](https://nodejs.org) 24 o una versión más nueva. Después ejecuta:

```sh
npm install -g https://github.com/chrisvasqm/jira-cli/releases/download/v0.5.1/jira-cli-0.5.1.tgz
```
