## English

You can now open a single ticket and read everything about it, including its comments.

### What's new

- **Read a ticket.** Run `jira ticket view ABC-123`. It shows the title, status, who works on it, the description, and a link to open it in Jira.
- **See the conversation.** The same command shows the 5 latest comments, so you know what is going on. Use `--comments 20` to see more, or `--comments 0` to hide them.
- **Use it with AI assistants.** Add `--json` to get the full ticket in a format that tools and AI assistants can read.

### How to install or update

You need [Node.js](https://nodejs.org) 24 or newer. Then run:

```sh
npm install -g https://github.com/chrisvasqm/jira-cli/releases/download/v0.2.0/jira-cli-0.2.0.tgz
```

## Español

Ahora puedes abrir un ticket y leer todo sobre él, incluidos sus comentarios.

### Novedades

- **Lee un ticket.** Ejecuta `jira ticket view ABC-123`. Muestra el título, el estado, quién trabaja en él, la descripción y un enlace para abrirlo en Jira.
- **Mira la conversación.** El mismo comando muestra los 5 comentarios más recientes, así sabes qué está pasando. Usa `--comments 20` para ver más, o `--comments 0` para ocultarlos.
- **Úsalo con asistentes de IA.** Agrega `--json` para obtener el ticket completo en un formato que otras herramientas y asistentes de IA pueden leer.

### Cómo instalar o actualizar

Necesitas [Node.js](https://nodejs.org) 24 o una versión más nueva. Después ejecuta:

```sh
npm install -g https://github.com/chrisvasqm/jira-cli/releases/download/v0.2.0/jira-cli-0.2.0.tgz
```
