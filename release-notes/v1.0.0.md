## English

jira-cli 1.0 is here: everything you need to work with Jira tickets from the terminal, for you and for your AI assistant.

### What you can do

- **See your board.** `jira board` shows the tickets in each column. Filter by status, by person, by sprint and more.
- **Read a ticket.** `jira ticket view ABC-123` shows the details, the description and the latest comments.
- **Create, change, move and delete tickets.** `jira ticket create`, `edit`, `move` and `delete`.
- **Talk on a ticket.** `jira comment list`, `add`, `edit` and `delete`.
- **Use more than one board.** `jira board list` and `jira board use 2`. Each project folder can use its own Jira site and board.

### New in 1.0

- **One install command for the newest version:**
  ```sh
  npm install -g https://github.com/chrisvasqm/jira-cli/releases/latest/download/jira-cli.tgz
  ```
- **A skill for AI assistants.** Run `npx skills add chrisvasqm/jira-cli` to teach Claude Code, Codex, Cursor and other assistants how to use the CLI safely.

### How to install or update

You need [Node.js](https://nodejs.org) 24 or newer. To install exactly this version, run:

```sh
npm install -g https://github.com/chrisvasqm/jira-cli/releases/download/v1.0.0/jira-cli-1.0.0.tgz
```

## Español

Llegó jira-cli 1.0: todo lo que necesitas para trabajar con tickets de Jira desde la terminal, para ti y para tu asistente de IA.

### Qué puedes hacer

- **Mira tu tablero.** `jira board` muestra los tickets de cada columna. Filtra por estado, por persona, por sprint y más.
- **Lee un ticket.** `jira ticket view ABC-123` muestra los detalles, la descripción y los comentarios más recientes.
- **Crea, cambia, mueve y borra tickets.** `jira ticket create`, `edit`, `move` y `delete`.
- **Conversa en un ticket.** `jira comment list`, `add`, `edit` y `delete`.
- **Usa más de un tablero.** `jira board list` y `jira board use 2`. Cada carpeta de proyecto puede usar su propio sitio de Jira y su propio tablero.
