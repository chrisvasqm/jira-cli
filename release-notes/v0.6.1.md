## English

This update fixes the setup again.

### What's fixed

- **Answers after the API token are read correctly.** Before, after you typed your token, `jira setup` could misread the board number and the project key, and save the wrong board. Now every answer is read as you type it, and the token stays hidden.

If your last setup saved the wrong board, run `jira setup` again.

### How to install or update

You need [Node.js](https://nodejs.org) 24 or newer. Then run:

```sh
npm install -g https://github.com/chrisvasqm/jira-cli/releases/download/v0.6.1/jira-cli-0.6.1.tgz
```

## Español

Esta actualización corrige otra vez la configuración.

### Qué se corrigió

- **Las respuestas después del token de API se leen bien.** Antes, después de escribir tu token, `jira setup` podía leer mal el número del tablero y la clave del proyecto, y guardar el tablero equivocado. Ahora cada respuesta se lee tal como la escribes, y el token sigue oculto.

Si tu última configuración guardó el tablero equivocado, ejecuta `jira setup` otra vez.

### Cómo instalar o actualizar

Necesitas [Node.js](https://nodejs.org) 24 o una versión más nueva. Después ejecuta:

```sh
npm install -g https://github.com/chrisvasqm/jira-cli/releases/download/v0.6.1/jira-cli-0.6.1.tgz
```
