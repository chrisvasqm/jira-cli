## English

You can now create tickets from the terminal.

### What's new

- **Create a ticket.** Run `jira ticket create --summary "Fix the login page"`. It is added to the project from your setup and you get its key and link.
- **Add the details at once.** Use `--type Bug`, `--description "..."` or `--description-file notes.md`, `--priority High`, `--assignee me`, `--add-label urgent` and `--parent ABC-10`.
- **Use another project.** Add `--project OPS` to create the ticket in a different project.
- **Use it with AI assistants.** Add `--json` to get the new ticket's key and link in a format that tools and AI assistants can read.

### How to install or update

You need [Node.js](https://nodejs.org) 24 or newer. Then run:

```sh
npm install -g https://github.com/chrisvasqm/jira-cli/releases/download/v0.6.0/jira-cli-0.6.0.tgz
```

## Español

Ahora puedes crear tickets desde la terminal.

### Novedades

- **Crea un ticket.** Ejecuta `jira ticket create --summary "Corregir la página de inicio de sesión"`. Se agrega al proyecto de tu configuración y recibes su clave y su enlace.
- **Agrega los detalles de una vez.** Usa `--type Bug`, `--description "..."` o `--description-file notas.md`, `--priority High`, `--assignee me`, `--add-label urgente` y `--parent ABC-10`.
- **Usa otro proyecto.** Agrega `--project OPS` para crear el ticket en otro proyecto.
- **Úsalo con asistentes de IA.** Agrega `--json` para obtener la clave y el enlace del ticket nuevo en un formato que otras herramientas y asistentes de IA pueden leer.

### Cómo instalar o actualizar

Necesitas [Node.js](https://nodejs.org) 24 o una versión más nueva. Después ejecuta:

```sh
npm install -g https://github.com/chrisvasqm/jira-cli/releases/download/v0.6.0/jira-cli-0.6.0.tgz
```
