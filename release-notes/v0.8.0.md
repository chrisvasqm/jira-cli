## English

You can now delete tickets from the terminal.

### What's new

- **Delete a ticket.** Run `jira ticket delete ABC-123`. The CLI shows the ticket's title and asks you to type "yes" first.
- **Skip the question in scripts.** Add `--yes` to delete without being asked. Scripts and AI assistants must pass `--yes`, so nothing is deleted by accident.
- **Tickets with sub-tasks.** Jira does not delete a ticket that has sub-tasks. Add `--with-subtasks` to delete the ticket and its sub-tasks together.

### How to install or update

You need [Node.js](https://nodejs.org) 24 or newer. Then run:

```sh
npm install -g https://github.com/chrisvasqm/jira-cli/releases/download/v0.8.0/jira-cli-0.8.0.tgz
```

## Español

Ahora puedes borrar tickets desde la terminal.

### Novedades

- **Borra un ticket.** Ejecuta `jira ticket delete ABC-123`. La CLI muestra el título del ticket y te pide escribir "yes" primero.
- **Salta la pregunta en scripts.** Agrega `--yes` para borrar sin que te pregunte. Los scripts y asistentes de IA deben usar `--yes`, así nada se borra por accidente.
- **Tickets con subtareas.** Jira no borra un ticket que tiene subtareas. Agrega `--with-subtasks` para borrar el ticket y sus subtareas juntos.

### Cómo instalar o actualizar

Necesitas [Node.js](https://nodejs.org) 24 o una versión más nueva. Después ejecuta:

```sh
npm install -g https://github.com/chrisvasqm/jira-cli/releases/download/v0.8.0/jira-cli-0.8.0.tgz
```
